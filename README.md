# Цифровой помощник тьютора: обработка наблюдений

Модуль разбирает записи тьютора, специалистов и родителей в свободной форме:
определяет тип записи, извлекает ключевые поля и проверяет, относится ли наблюдение
к отслеживаемым зонам развития. Результат - структурированный JSON-отчёт
со степенью уверенности и пометкой «требуется уточнение».

## Быстрый старт

Нужен Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Запуск тестов:

```bash
pytest
```

Проверка стиля кода (PEP8, docstrings, отсутствие «магических чисел»), настройки лежат в `pyproject.toml`:

```bash
ruff check .
```

Запуск всего пайплайна на `dataset.json`:

```bash
python main.py
```

## Режимы проверки зон

| Режим | Команда | Поведение |
|---|---|---|
| auto | `python main.py` | GigaChat, если задан ключ, иначе ключевые слова |
| llm | `python main.py run --mode llm` | GigaChat; при ошибке или некорректном ответе запись уходит в запасной режим |
| fallback | `python main.py run --mode fallback` | только ключевые слова, работает без интернета и ключей |

Чтобы подключить GigaChat, скопируйте `.env.example` в `.env` и укажите ключ авторизации:

```
GIGACHAT_CREDENTIALS=<ключ авторизации из личного кабинета>
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2
GIGACHAT_VERIFY_SSL_CERTS=False
```

Подбор порога `unknown` для классификатора воспроизводится командой:

```bash
python main.py sweep
```

## Использование как библиотеки

```python
from tutor_assistant import check_zone, classify, extract

extract("05.03.2025. Ребёнок CH-0421, тьютор Иванова А. С. Сон 6 ч 30 мин")
classify("Рекомендация от 12 марта 2025 г. по ребёнку CH-0107: ввести сенсорную паузу")
check_zone("отказ от еды третий день подряд")
```

## Архитектура

Каждая запись проходит три шага:

1. `classify` определяет тип записи и уверенность. Работает на взвешенных эвристиках:
   если разрыв между двумя лучшими типами меньше порога, возвращается `unknown`.
2. `extract` извлекает дату, ID ребёнка, автора, длительность сна и явно указанную зону
   с помощью регулярных выражений.
3. `check_zone` проверяет, относится ли запись к отслеживаемым зонам, и объясняет вывод.
   Решение принимает GigaChat, его ответ проверяется на соответствие формату. Если ключа
   или сети нет либо ответ некорректен, используется поиск по ключевым словам.

Результаты собираются в JSON-отчёт. Для каждой записи в нём есть признак
«требуется уточнение» с причинами, а в сводке - доля таких записей.

| Файл | Назначение |
|---|---|
| `tutor_assistant/extractor.py` | Часть 1: извлечение полей |
| `tutor_assistant/classifier.py` | Часть 2: классификация типа записи |
| `tutor_assistant/zones.py` | Часть 3: проверка зон, запасной режим на словаре основ |
| `tutor_assistant/llm.py` | клиент GigaChat, промпт и строгий разбор ответа |
| `tutor_assistant/verdict.py` | структура результата проверки зоны |
| `tutor_assistant/pipeline.py` | сквозной пайплайн, признак «требуется уточнение», перебор порога |
| `tutor_assistant/report.py` | markdown-таблицы для отчёта |
| `tutor_assistant/config.py` | все пороги и параметры в одном месте |
| `main.py` | CLI |
| `dataset.json` | тестовые данные из приложения 1 |
| `data/classification_validation.json` | размеченная выборка для подбора порога unknown |
| `tests/` | тесты pytest |

Подробности о выбранных подходах, компромиссах и результатах - в [RESULTS.md](RESULTS.md).

# Мотивация участия в проекте:

Мне интересен проект прежде всего как возможность участвовать в создании MVP с нуля: от прототипа до первого работающего агента. Это даёт свободу в выборе подходов, пространство для экспериментов и быструю обратную связь от реальных пользователей.

Моя роль видится в ML-составляющей продукта. Это может быть и разработка пайплайнов извлечения данных, и исследование сложных кейсов, и анализ ошибок для повышения точности. Я открыта к разным задачам в рамках ML-трека, готова быстро осваивать и включаться в новые задачи.

На проект могу выделять 20 часов в неделю в течение как минимум 3 месяцев, с возможностью продления при успешных результатах. В перспективе заинтересована участвовать в развитии продукта на постоянной основе.
